# 项目报告与验收

- [项目报告书](牛逼外卖-项目报告书.pdf) 含实机截图、Blender 同角度校样、关键模型前后对照和发行记录。
- [版本验收](版本验收.json) 记录本次构建、浏览器输入、网页整单与离线成品的校验值。
- 玩家提前下车去红棚时，手机黄线和展开地图的副标题会一起指向车辆或可装餐的尾箱侧。[取餐测试](../game/qa/launch-pickup.mjs)覆盖远处停车和店旁停车。
- 同时按 W 和 ↑ 时，松开其中一个仍可加速。按着 Ctrl 松开移动键也会正确收油、停步。[键盘实测](../game/qa/launch-input.mjs)
- 必须先过门线才会触发保安。球场外圈和紫藤近道都能完成首单，车况归零扣罚后可重试。65 秒签收仍有准时奖。[本版规则实测](关卡规则回归.txt) · [规则脚本](../game/qa/first-order.sim.mjs) · [追逐与侧踢](../game/qa/patrol-pressure.mjs)
- 浏览器实测模拟骑手模型第一次返回 503，随后自动取回 21 骨骼模型。[弱网加载检查](../game/qa/aholo-weak-network.mjs)
- [中国大陆运营商探测](大陆直连实测.json) 给出探针城市、运营商、响应状态和可回查的公开测量编号。
